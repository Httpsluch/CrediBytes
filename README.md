# LoanGuard PH — Browser Extension

Detects and flags potentially illegitimate Online Lending Application (OLA)
advertisements on Facebook using the SEC Philippines registry.

---

## Folder Layout

```
loanguard/
│
├── manifest.json               # Chrome Extension Manifest V3 config
│
├── icons/
│   ├── icon16.svg              # Source SVGs — convert to PNG before loading
│   ├── icon48.svg
│   ├── icon128.svg
│   ├── icon16.png              # Required by Chrome (generate from SVG)
│   ├── icon48.png
│   ├── icon128.png
│   └── README_ICONS.txt        # How to generate the PNGs
│
└── src/
    ├── sec_reference.json      # SEC OLA registry (153 records, 47 KB)
    │                           # Generated by: python build_sec_reference.py
    │                           # Source:       dataset_output/ph_ola_final.csv
    │
    ├── sec_reference.js        # Wraps the JSON as: const SEC_REFERENCE = [...]
    │                           # Injected before matcher.js in content_scripts
    │
    ├── matcher.js              # JS port of match_ad_links.py
    │                           # Exports: window.LoanGuardMatcher.matchUrl()
    │                           # Runs locally — no network call needed
    │
    ├── content.js              # Main content script
    │                           # - MutationObserver detects Facebook sponsored posts
    │                           # - Extracts landing URL + ad text
    │                           # - Calls matcher.js (Stage 2, instant, local)
    │                           # - Calls FastAPI backend (Stage 1, async)
    │                           # - Injects badge into ad element
    │
    ├── background.js           # Manifest V3 service worker
    │                           # - Handles install lifecycle
    │                           # - Relays messages between content ↔ popup
    │
    ├── popup.html              # Extension popup UI (340px wide)
    ├── popup.js                # Reads chrome.storage.local for scan history
    │
    └── (future)
        └── options.html        # Settings page (backend URL, enable/disable)
```

## How It Works

```
Facebook Feed (browser)
        ↓
MutationObserver (content.js)
  Detects <div role="article"> with "Sponsored" label
        ↓
Extract landing URL + ad text
        ↓
        ├── LOCAL  matcher.js + sec_reference.js
        │   Pass 1: Play Store package ID match
        │   Pass 2: App Store numeric ID match
        │   Pass 3: Domain / subdomain match
        │   Pass 4: Exact normalized name match
        │           ↓
        │   legitimate / unverified / likely_legitimate + reason
        │
        └── REMOTE  FastAPI backend (Render)
            POST /predict
            { company_name, platform_name }
                    ↓
            { is_app: bool, probability: float }
            (Stage 1 LightGBM model)
                    ↓
Badge injected into ad  →  chrome.storage.local  →  Popup UI
```

---

## Badge Meanings

| Badge | Colour | Meaning |
|---|---|---|
| ✅ SEC Verified | Green | URL matched SEC-registered Play Store / App Store / website |
| 🔍 Likely Legitimate | Amber | App name matched SEC registry but URL couldn't be verified |
| ⚠️ Unverified | Orange | No match found in SEC registry |
| 🚨 Unregistered App | Red | App store link with no SEC declaration — highest risk |

## Setup

### 1. Generate PNG icons

```bash
pip install cairosvg
cd icons/
cairosvg icon16.svg  -o icon16.png
cairosvg icon48.svg  -o icon48.png
cairosvg icon128.svg -o icon128.png
```

### 2. Load in Chrome

1. Go to `chrome://extensions`
2. Enable **Developer mode** (top right)
3. Click **Load unpacked**
4. Select the `loanguard/` folder

### 3. Configure backend URL

In `src/content.js`, update line 14:
```js
const BACKEND_URL = "https://your-render-app.onrender.com";
```

### 4. Update SEC reference data

When `ph_ola_final.csv` is updated, regenerate `sec_reference.js`:
```bash
python build_sec_reference.py
```
Then reload the extension in `chrome://extensions`.

## Backend (FastAPI — separate repo)

The extension calls `POST /predict` on the FastAPI backend deployed on Render.

**Request:**
```json
{ "company_name": "Wefund Lending Corp.", "platform_name": "JuanHand" }
```

**Response:**
```json
{ "is_app": true, "probability": 0.87 }
```

The backend loads `ph_ola_lightgbm_is_app_model.pkl` (Stage 1 LightGBM model).
The extension degrades gracefully if the backend is unreachable — the local
SEC matcher (Stage 2) still runs and provides a verdict.
